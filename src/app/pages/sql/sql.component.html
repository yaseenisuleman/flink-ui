The SQL editor runs statements through the Flink SQL Gateway, a separate service. The dashboard looks for it at ./sql-gateway on its own host. The flink-ui container proxies that path to the gateway's REST port; point SQL_GATEWAY_URL at it (default http://sql-gateway:8083 ).

Start one next to the JobManager with:

bin/sql-gateway.sh start-foreground \
  -Dsql-gateway.endpoint.rest.address=0.0.0.0 \
  -Drest.address=<jobmanager-host>
